# SecMate User Study Questionnaires
This folder contains the complete set of questionnaires used in the large-scale controlled user study for SecMate.

1. `pre_experiment_questionnaire.pdf`: Administered at the beginning of the experimental session to collect foundational participant information.
2. `tech_proficiency.pdf`: A comprehensive assessment designed to map the participant's baseline technological and cybersecurity troubleshooting experience.
3. `post_scenario_questionnaire.pdf`: Completed immediately after finishing each of the 5 predefined cybersecurity troubleshooting scenarios.
4. `post_experiment_questionnaire.pdf`: Administered at the absolute end of the experimental session to gather system-level evaluation data and macro preferences.

The following diagram demonstrates the sequential path a participant takes through the materials during the experimental session:

```
[ Step 1: Pre-Experiment Questionnaire & Personality Links ]
                             │
                             ▼
              [ Step 2: Tech Proficiency Test ]
                             │
                             ▼
         [ Step 3: 5-Minute Warm-Up Chat with SecMate ]
                             │
                             ▼
    [ Step 4: Troubleshooting Scenarios (1 to 5) ] ──► [ Post-Scenario Form After Each ]
                             │
                             ▼
         [ Step 5: Post-Experiment Questionnaire ]
```
